# Runtime base-image policy

This directory intentionally contains **no third-party images**. The supplied founder references (Tibo profile photo, platform screenshots, OpenAI/Codex logo and previous social artwork) are used only to understand design hierarchy; we have not verified rights to redistribute them in the public repository.

When running the Skill, users may upload:
- An image they designed or have permission to modify/reuse.
- An original/source post screenshot for **fact extraction**; do not republish the raw UI screenshot unless allowed.
- Their own brand mark, if they choose.

If a base image is missing or unauthorized, default to a clean neutral 3:4 editorial poster. Do not synthesize an apparently official third-party endorsement, impersonate Tibo's profile, or make a screenshot appear to be a platform-issued announcement.

A user-provided base stays within the run; it is **not** automatically committed or published to Labs.
