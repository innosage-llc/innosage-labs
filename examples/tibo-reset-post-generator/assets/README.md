## How to use

From a local Git checkout, the source image is available under `examples/tibo-reset-post-generator/assets/`. For ordinary ChatGPT Web, open the GitHub file and download/attach the **actual PNG** into the conversation so GPT's image-editing tool can access its pixels. A GitHub path or browser screenshot alone may not deliver the original image to the renderer. If the image can't be read, report `INCOMPLETE — BASE_IMAGE_UNAVAILABLE` instead of recreating the poster.

Retain the original committed image **unchanged**. Edit a separate output copy for each new post. Source screenshots are for fact extraction and should not be committed or auto-posted.
