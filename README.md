# InnoSage Labs

**Built in practice. Shared for reuse.**

InnoSage Labs is a public collection of small tools, agent workflows, and engineering examples distilled from real work at [InnoSage](https://innosage.co). The goal is simple: **find something useful, try it, and adapt it to your own project.**

实战沉淀，开放复用。这里分享我们实际开发中形成的工具、工作流和工程经验。

## What belongs here?

- **Skills and workflows** with clear prerequisites, concrete steps, and failure paths.
- **Small examples** that someone else can understand and reproduce.
- **Lessons from shipping** that distinguish observed behavior from a proposed pattern.

We prioritize things that were useful in a real project—not generic prompt collections. A text workflow here is a **template**, not a deployed automation or a guarantee that any agent will execute it correctly.

## How this repository works

1. Discover a small reusable artifact here.
2. Follow its **canonical source** when a project already lives elsewhere.
3. Check the stated prerequisites, limitations, and verification steps.
4. Adapt it to your environment; report issues or improvements with reproducible evidence.

Labs is a **curated entry point, not a mirror**. Draft Skills and InnoSage DevTools remain maintained in their own repositories. Their code, releases, requirements, and bug reports belong upstream.

## Trust and contribution

Every contribution should state **what it does, how to try it, what was actually verified, and what is not guaranteed**. Do not include credentials, private user data, sensitive transcripts, internal-only infrastructure details, or unreviewed private source code.
